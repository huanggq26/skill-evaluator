# attack-surface-tag-system-refactor

## Why

攻击面标签是安全维度**覆盖面的唯一开关**：它决定"测哪些"，进而在报告里决定"结论是结构合规还是安全已验证"。当前体系有四类实证缺陷。

**实测一：标签集内聚性不达标**（2026-10-10，来源 `scripts/surface_tagging.py`）

- `fs_net_cred` 一个标签打包了**三个**独立能力面（文件系统 / 网络 / 凭证），判定信号明显分三簇（`open(`、`os.remove` ｜ `requests.`、`urllib`、`httpx`、`fetch` ｜ `token`、`令牌`、`getenv`、`~/.ssh`）。命中即同时声称三个面存在，其 ASI 映射必然是折中。
- `secret_memory` 把"写日志 / 持久化"与"持有凭证缓存"两类不同证据混在一起。

**实测二：恒真信号**（6 个真实异质技能，`SAMPLE_ROOT`）

`secret_memory` 在 **6/6** 技能上全部命中，取证显示命中来源几乎全是信号 `\.md`——该信号匹配到了 **`SKILL.md` 文件名本身**。同类还有 `\.json`、`search`。恒真信号制造虚假召回，掩盖真实漏检。

**实测三：漏检**（同批样本）

`aihot` 的 `references/api.md`、`README.md` 等文件共含 55 处 `http` / `api` / `fetch` / `request` 字样，是明确的联网抓取技能，但 `fs_net_cred` **未命中**——信号只覆盖 `requests.` / `urllib` / `httpx` / `fetch` 四种写法。

**实测四：词形覆盖不全**

68 个判定信号中中文占 28（41%）、英文占 40（59%）；`user_content` 与 `prompt_intent` 为**纯中文信号标签**，纯英文技能存在系统性漏打标风险。凭证类只有 `token` / `令牌`，缺 `credential` / `secret` / `api_key`。

**实测五：映射漂移**

`TAG_TO_ASI`（代码）与 `Mapping-Matrix.md` 准入表逐项比对 **9/9 全部不一致**，且两条路径无对账守卫（已由 `2026-10-09-surface-tag-asi-mapping-alignment` 承载）。

**分类学依据缺失**：标签集从历史概念改造而来，此前缺少严谨推导。本次补上——攻击面标签本质是"**能力 / 权限面枚举**"，与移动端权限组、浏览器扩展权限声明、OAuth scope、MCP 能力声明同属一个已成熟的问题域；由此确立"能力面（上游）→ 风险后果 ASI（下游）"的推导链，同时解释了为何不能用 ASI 直接充当标签（静态扫描观测不到下游结论）。

**完整论证与方案**：`~/Downloads/攻击面标签体系改造方案_2026-10-10.md`

## 任务类别判定

- 判据：是否改变对外可观察行为 → **是**（改标签集、判定信号与映射，会改变生成的探测集合、产物目录结构与覆盖面告警）
- 分流：**行为变更** → 由规范区变更承载任务态，不登记 TASKLOG（避免双写）

## What Changes

1. **标签集重构**：9 → 11。拆 `fs_net_cred` → `fs_access` / `net_egress` / `cred_access`；拆 `secret_memory` → `state_persist`（凭证面并入 `cred_access`）；收窄 `user_content` 与 `tool_calls` 的过宽信号；其余 6 个保留。
   - 改前：一个"是非题"标签可能捆绑三个能力面。
   - 改后：一标签一场景，多能力并存由多个标签同时命中表达。
2. **判定分两层（决策 U3：不引入 LLM 参与打标）**：S1 声明层（清单文件解析）→ S2 词形层（概念 → 中英词形 + 语法级特征）。
   - 改前：平铺正则 / 关键词，中英混排。
   - 改后：概念 → 词形（中英 + 变体）结构；代码侧改用语法特征（AST 调用节点 / import 识别）而非字面。
   - **影响评估**：同义改写实测显示 3 个标签会丢失（详见下），均**可由词表补齐与语法层补回**；残余风险由默认纳入兜底与基准集对冲。
3. **输出全量判定**：未命中标签也输出 `miss` + 判据（改前只输出命中，是漏检长期静默的直接原因）。
4. **防漏检机制**：召回优先阈值、基准测试集、全量反向对照、词表变更门禁、恒真信号剔除（命中率 ≥ 95% 进剔除候选）。
5. **运行时兜底**：承认静态打标的**固有召回上限**（LLM 运行时动态生成的命令不在任何静态文本中）。**运行时能力观测独立立项（决策 U8）**——需执行隔离、代理、沙箱权限，与现有流水线架构差异大。本次仅做 RT-0（产物反推）+ 预留 `runtime` 来源字段；漏检代价由**高风险面默认纳入** + 判定来源标注（`static` / `default`）降低。
6. **映射对齐**：与 `2026-10-09-surface-tag-asi-mapping-alignment` 协同，映射值由单一权威源派生并加逐标签校验。
