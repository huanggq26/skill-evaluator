## 技术方案

完整方案与实测数据见工作文档 `输出报告模板约束优化方案.md`（下载目录），本变更落地时以其为准，此处不复制需求内容。

## 关键取舍

| 决策 | 取舍理由 |
|---|---|
| 阶段 4 采用**骨架模板**而非完全复刻阶段 0 机制 | 阶段 0 机制是「字段 → 占位」机械回填，无条件渲染能力；阶段 4 存在条件小节与动态编号。内容生成逻辑经大量实测打磨，整体重写风险高 |
| 职能分离取**严格口径** | 现状已出现评分报告写入问题条目；可行动性由「指向问题报告」补偿，而非在评分报告内保留建议 |
| 文件名统一英文、标题统一中文 | 文件名禁中文（防跨平台编码与 Unicode 归一化导致检索漏命中）；该约束只限文件名，内容与标题仍用中文 |
| 主观维度**保持 LLM 裁定**，不改为脚本代填 | 脚本填语义结论等同编造（违反不臆造纪律）；改为以阶段完成门禁暴露未裁定状态，而非静默渲染为「无」 |
| 阶段 0 空槽位语义分离 | 「无」一字承载两种相反语义（已检查无问题 / 根本没结论），读者无法分辨，属静默降级 |
