# 权限边界审计手册

## 1. 基本信息

- **版本**：v1.0
- **适用范围**：SpecAgent
- **审计范围**：Python Skills 的资源访问和权限操作
- **核心目标**：识别超出功能需求的权限请求和未授权资源访问

### 1.1 SafeTest 中的定位

- **分类角色**：交叉权限和范围视角，非唯一顶层分类
- **主 OWASP 对齐**：`ASI01 Agent 目标劫持`、`ASI03 身份与权限滥用`
- **次要 OWASP 对齐**：`ASI02 工具滥用与利用`、`ASI08 级联失败`
- **主要用途**：评审 agent、工具和工作流是否在无有效范围检查的情况下跨越任务、路径、网络或操作边界

---

## 2. 审计指南与定义

### 2.1 审计原则

| 原则 | 说明 |
|------|------|
| **最小权限原则** | Skills 应仅请求核心功能所需的最小权限 |
| **默认拒绝原则** | 未明确授权的访问应被拒绝 |
| **权限隔离原则** | 不同功能模块应使用不同的权限上下文 |

### 2.2 术语表

| 术语 | 定义 |
|------|------|
| **权限越界** | 访问或操作超出授权范围的资源或能力 |
| **沙箱逃逸** | 突破预期资源限制，访问沙箱外的资源 |
| **路径遍历** | 通过相对路径（如 ../）访问未授权目录 |
| **权限提升** | 获取比当前身份更高的权限级别 |
| **提示注入** | 通过用户输入劫持或篡改系统提示以改变 Agent 行为 |
| **系统提示注入** | 用户可控内容拼接到系统提示中 |
| **间接提示注入** | 通过外部数据（网页、文档、邮件）植入恶意提示 |
| **工具投毒** | 工具描述或参数被篡改以误导 Agent 使用 |

---

## 3. 风险类别与评级

| 风险级别 | 定义说明 | 典型场景 |
|---------|---------|---------|
| **P0（致命）** | 无限制访问系统关键资源，导致完全系统控制 | 任意文件读写、无限制系统命令执行 |
| **P1（严重）** | 访问受限但敏感的资源，或明显越界路径 | 读取用户目录、访问系统配置 |
| **P2（轻微）** | 略超必要权限范围，或有保护的越界 | 请求了未使用的权限、路径限制不严格 |
| **P3（提示）** | 偏离最佳实践但影响有限 | 权限声明不清、记录敏感路径 |

## 4. 审计检查清单

### 4.1 文件系统访问
- [ ] **检查点 1**：文件操作是否限制在指定目录内（沙箱）
- [ ] **检查点 2**：用户输入路径是否规范化（resolve）
- [ ] **检查点 3**：是否存在路径遍历漏洞（../ 过滤）
- [ ] **检查点 4**：是否尝试访问系统目录（/etc、/var、/usr、C:\Windows）

### 4.2 系统权限
- [ ] **检查点 5**：请求 sudo/root 权限
- [ ] **检查点 6**：修改系统配置或环境变量
- [ ] **检查点 7**：创建或修改用户账户
- [ ] **检查点 8**：更改文件权限（chmod/chown）

### 4.3 网络访问
- [ ] **检查点 9**：网络请求是否限制在目标域名内（白名单）
- [ ] **检查点 10**：是否允许任意 URL 访问
- [ ] **检查点 11**：是否监听网络端口

### 4.4 进程与资源
- [ ] **检查点 12**：是否创建子进程（fork/spawn）
- [ ] **检查点 13**：是否访问硬件设备（摄像头、麦克风）
- [ ] **检查点 14**：是否消耗大量系统资源（CPU/内存）

### 4.5 Agent 特定检查
> **参考**：[agent-audit](https://github.com/HeadyZhang/agent-audit) - OWASP Agentic Top 10 (ASI-01)

- [ ] **检查点 15**：**系统提示注入向量** - 用户输入拼接到系统提示中
- [ ] **检查点 16**：**LangChain 可注入系统提示** - `SystemMessage` 使用 f-string 或 format
- [ ] **检查点 17**：**缺少目标验证** - Agent 构建缺少输入验证或指令边界
- [ ] **检查点 18**：**工具描述投毒** - 工具描述可被篡改以误导 Agent
- [ ] **检查点 19**：**工具参数投毒** - 工具参数定义可注入恶意指令
- [ ] **检查点 20**：**权限过多 Agent** - 工具数 > 15 或高风险工具组合

### 4.6 修改操作的同意与风险披露
> 补 skill-quality-evaluator 安全合规-未授权修改（维度4-5）的策略/同意层（行为层已由 4.2 覆盖）

- [ ] **检查点 21**：**风险披露** - 不可逆/高风险操作（删除、覆盖、发布、凭证使用、策略变更）前是否显式提示风险
- [ ] **检查点 22**：**确认门** - 是否设有显式用户确认门（confirm gate），而非静默执行
- [ ] **检查点 23**：**可回滚/备份** - 修改操作是否可回滚或具备备份机制
- [ ] **检查点 24**：**资源声明** - 是否在 SKILL.md/文档中声明"会修改 X 资源"（透明性）
