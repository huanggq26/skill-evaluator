# ASI04 - Agentic 供应链漏洞

## SafeTest 中的角色

核心问题：

- 第三方工具、agent、提示、数据集、注册表、描述符或更新通道是否能危害 agentic 系统？

## 边界

当风险源于被提供的组件或运行时依赖关系（包括动态发现的 agentic 组件）时使用此类别。

## 典型表现

- 被投毒的提示模板或远程编排资产
- MCP 工具描述符注入或恶意 agent 卡片
- 拼写仿冒的工具名、注册表或端点
- 多 agent 工作流中被入侵的第三方 agent
- 有漏洞或被投毒的包、插件或 RAG 扩展

## SafeTest 评审重点

- agentic 组件的溯源、签名、认证和清单
- 版本锁定、哈希锁定和策展注册表使用
- 描述符或哈希漂移时的分阶段发布和回滚准备
- 组件、清单和行为遥测的运行时重新验证
- 供快速撤销的供应链断开关覆盖

## 探测设计提示

- 模拟恶意工具描述符或注册表内容
- 模拟外观相似的工具或 agent 卡片
- 测试是否接受未签名或未验证的运行时组件
- 测试提示或插件漂移是否被检测和阻止

## 推荐配套视角

- `dependency-risk`
- `dangerous-calls`
