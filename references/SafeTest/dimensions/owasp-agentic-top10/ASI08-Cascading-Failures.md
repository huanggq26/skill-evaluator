# ASI08 - 级联失败

## SafeTest 中的角色

核心问题：

- 一个坏输入、坏决策、坏内存条目、坏工具操作或坏 agent 入侵是否能扩散为跨 agent、工作流或租户的更广泛系统损害？

## 边界

当传播和放大是安全故事时使用此类别。原始缺陷可能属于其他 ASI 类别，但被衡量的损害在于扩散。

## 典型表现

- 无验证的规划器-执行器耦合
- 被投毒的内存跨多个任务复用
- 下游 agent 重复执行不安全的工具调用
- 反馈循环、重试风暴或队列风暴
- 策略或治理漂移，悄无声息地扩大自动化范围

## SafeTest 评审重点

- 爆炸半径限制，如配额、上限和熔断器
- 规划与执行之间的独立策略执行
- 传播前的下游验证和人工门
- 基于行为基线的漂移检测
- 整条链上的防篡改血缘和可追溯性

## 探测设计提示

- 测试一个虚假告警或虚假记忆是否扩散到多个操作
- 测试规划器是否能将不安全步骤推入自动执行器
- 测试重复失败是否被节流还是被允许放大
- 测试回滚和遏制在被触发后是否能停止传播

## 推荐配套视角

- `permission-boundary`
- `dangerous-calls`
- `sensitive-info-leak`
