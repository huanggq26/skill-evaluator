# 依赖风险审计手册

## 1. 基本信息

- **版本**：v1.0
- **适用范围**：SpecAgent
- **审计范围**：Python Skills 的第三方依赖（requirements.txt、pyproject.toml、import 语句）
- **核心目标**：识别依赖相关的供应链风险、已知漏洞和权限滥用

### 1.1 SafeTest 中的定位

- **分类角色**：交叉供应链视角，非唯一顶层分类
- **主 OWASP 对齐**：`ASI04 Agentic 供应链漏洞`
- **次要 OWASP 对齐**：`ASI05 非预期代码执行`、`ASI07 不安全的 Agent 间通信`、`ASI10 流氓 Agent`
- **主要用途**：评审第三方代码、MCP 服务器、注册表、描述符和更新通道的溯源和入侵风险

## 2. 审计指南与定义

### 2.1 审计原则

| 原则 | 说明 |
|------|------|
| **描述与实质分离** | 不信任 Skill 的"零依赖""纯本地"声明，必须独立验证依赖树 |
| **供应链安全** | 即使 Skill 本身无害，其依赖可能已被入侵或存在漏洞 |
| **最小依赖原则** | Skills 应仅依赖必要的库，避免过度依赖 |

### 2.2 术语表

| 术语 | 定义 |
|------|------|
| **供应链攻击** | 通过入侵第三方依赖来攻击终端用户的攻击方式 |
| **已知漏洞（CVE）** | 公开披露的安全漏洞，通常有对应的 CVE 编号 |
| **隐藏依赖** | 未在声明中显式列出但在运行时动态加载的依赖 |
| **安装脚本风险** | setup.py、postinstall 脚本执行的任意代码 |
| **MCP 服务器** | Model Context Protocol 服务器，为 Agent 提供工具能力 |
| **版本锁定** | 使用 `@version` 显式指定依赖版本，避免自动更新 |
| **Rug Pull** | 依赖包在发布后被恶意修改（版本不变但内容变化） |
| **拼写仿冒** | 使用相似名称模仿流行包的恶意包 |

---

## 3. 风险类别与评级

| 风险级别 | 定义说明 | 典型场景 |
|---------|---------|---------|
| **P0（致命）** | 依赖存在严重 CVE 且无法升级，或来源被入侵 | 使用有 RCE 漏洞的旧版本、依赖恶意仓库 |
| **P1（严重）** | 依赖存在中高风险 CVE 但可升级，或安装脚本执行危险操作 | PyPDF2 旧版本、setup.py 下载外部脚本 |
| **P2（轻微）** | 依赖版本较旧但无已知 CVE，或轻微权限问题 | 依赖版本过旧、依赖过多 |
| **P3（提示）** | 略偏离最佳实践 | 版本未锁定、dev 依赖未分离 |

## 4. 审计检查清单

### 4.1 依赖声明扫描
- [ ] **检查点 1**：检查是否存在 requirements.txt / pyproject.toml
- [ ] **检查点 2**：依赖版本是否锁定（如 requests==2.28.1）
- [ ] **检查点 3**：是否有版本范围约束（如 requests>=2.28.0）
- [ ] **检查点 4**：是否有 Git/URL 来源依赖（非 PyPI）

### 4.2 依赖来源验证
- [ ] **检查点 5**：依赖是否来自官方 PyPI（非私有镜像）
- [ ] **检查点 6**：是否有内部/私有仓库依赖
- [ ] **检查点 7**：依赖包的维护状态（最后更新时间）

### 4.3 漏洞扫描
- [ ] **检查点 8**：使用 CVE 数据库检查依赖版本是否有已知漏洞
- [ ] **检查点 9**：检查依赖的依赖（传递依赖）是否有漏洞
- [ ] **检查点 10**：评估漏洞可利用性和影响范围

### 4.4 安装脚本检查
- [ ] **检查点 11**：setup.py 是否包含网络下载或系统命令
- [ ] **检查点 12**：是否有 postinstall 脚本执行额外操作
- [ ] **检查点 13**：安装过程是否请求额外权限

### 4.5 MCP 供应链风险（Agent 特定）
> **参考**：[agent-audit](https://github.com/HeadyZhang/agent-audit) - OWASP Agentic Top 10 (ASI-04)

- [ ] **检查点 14**：**未验证的 MCP 来源** - MCP Server 来源未经验证
- [ ] **检查点 15**：**版本未锁定** - 使用 `npx -y package` 而非 `npx -y package@x.y.z`
- [ ] **检查点 16**：**MCP Rug Pull 检测** - MCP Server 版本与基线不匹配
- [ ] **检查点 17**：**跨服务器工具遮蔽** - 多个 MCP Server 中存在同名 Tool
- [ ] **检查点 18**：**HTTP 传输** - MCP Server 使用 HTTP 而非 HTTPS
- [ ] **检查点 19**：**未验证的 RAG 数据源** - 向量数据库或知识库来源未经验证
